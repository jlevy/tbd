SseHub.attach installs response error and request close listeners only after writing replay/current frames and only then registers the client. A disconnect or emitted stream error during initial writes can escape cleanup or leave a dead response registered. Install lifecycle listeners and client membership before any frame write, key cleanup to response close as well as request close, keep drop idempotent, and add a synchronous close/error interleaving regression.
