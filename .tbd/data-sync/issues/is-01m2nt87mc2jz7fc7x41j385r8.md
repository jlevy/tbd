GitHub Actions run 35137849677 job 104934614770 fails two ensure-gh-cli black-box tests on Windows because the tests replace PATH with Git Bash's POSIX spelling before Node resolves the outer bash executable. Resolve bash.exe through the native PATH first, use that absolute executable for Bash subprocesses, retain POSIX PATH inside Git Bash, add spawn-error diagnostics, and verify the hosted Windows job.

## Notes

Second hosted rerun (Actions 35140945527) proved BASH_ENV forced Linux/x86_64, then exposed the same Git Bash .exe precedence for curl, sha256sum, and mv: real Windows commands bypassed extensionless mocks, so the checksum and publish-race scenarios were not controlled. The process-scoped Bash environment now defines curl, sha256sum, and mv functions as well as uname; they resolve before the .exe commands while remaining confined to the two black-box children. Production installer code remains unchanged. Focused installer suite passes 35/35 locally; all non-Windows hosted jobs on the rerun are green. Awaiting another Windows run.
