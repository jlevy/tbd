GitHub Actions run 35137849677 job 104934614770 fails two ensure-gh-cli black-box tests on Windows because the tests replace PATH with Git Bash's POSIX spelling before Node resolves the outer bash executable. Resolve bash.exe through the native PATH first, use that absolute executable for Bash subprocesses, retain POSIX PATH inside Git Bash, add spawn-error diagnostics, and verify the hosted Windows job.

## Notes

Three hosted Windows iterations exposed and resolved the complete Git Bash command-resolution chain. The tests now resolve bash.exe through the native Windows PATH before supplying a POSIX PATH, and the two black-box children receive process-scoped Bash functions for uname, curl, sha256sum, and mv so real .exe tools cannot bypass the fixtures. Production ensure-gh-cli.sh is unchanged. Local focused installer validation passes 35/35; independent final review found no actionable issues; GitHub Actions run 35142252445 passed Windows Node 24, macOS, both Ubuntu jobs, Coverage & Lint, Benchmark, and secret scanning on d4f6169c.
