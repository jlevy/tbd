GitHub Actions run 35137849677 job 104934614770 fails two ensure-gh-cli black-box tests on Windows because the tests replace PATH with Git Bash's POSIX spelling before Node resolves the outer bash executable. Resolve bash.exe through the native PATH first, use that absolute executable for Bash subprocesses, retain POSIX PATH inside Git Bash, add spawn-error diagnostics, and verify the hosted Windows job.

## Notes

Root cause confirmed from check annotations and independent subagent reproduction: Node/Win32 searched for the outer bash executable through a POSIX-form PATH, so spawnSync returned ENOENT (status null) before Git Bash launched. The test harness now resolves bash.exe through the native PATH once, uses that executable for every Bash subprocess, converts the script argument to a Git Bash path, and includes spawn errors in black-box assertion diagnostics. Production ensure-gh-cli.sh is unchanged. Local validation: combined installer/integration/setup suite 102/102; focused installer suite 35/35; lint/typecheck/action-pin gate pass; format check pass.
