GitHub Actions run 35137849677 job 104934614770 fails two ensure-gh-cli black-box tests on Windows because the tests replace PATH with Git Bash's POSIX spelling before Node resolves the outer bash executable. Resolve bash.exe through the native PATH first, use that absolute executable for Bash subprocesses, retain POSIX PATH inside Git Bash, add spawn-error diagnostics, and verify the hosted Windows job.

## Notes

First hosted rerun (Actions 35139991671) proved the native bash.exe resolution fixed spawnSync: both black-box tests now launched. It exposed a second Windows-only fixture issue: Git Bash preferred its real uname.exe over the extensionless PATH mock, so the production script correctly refused MINGW and the race fixture never ran. The harness now supplies the deterministic Linux/x86_64 uname as a Bash function through BASH_ENV, which Bash sources before the script and resolves before uname.exe. Production ensure-gh-cli.sh remains unchanged. Focused installer suite remains 35/35; full non-Windows hosted jobs on the first rerun are green. Awaiting a fresh Windows run.
